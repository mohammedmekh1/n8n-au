# ❓ الأسئلة المتكررة (FAQ)

## 📌 أسئلة عامة

### س1: ما هي المنظومة العالمية للحج والعمرة؟

**ج:** هي نظام آلي متكامل لإدارة خدمات الحج والعمرة بالإنابة عن المتوفين، المرضى، والعاجزين. تعتمد على الذكاء الاصطناعي والأتمتة لتقليل التدخل البشري إلى الحد الأدنى مع ضمان الشفافية المطلقة.

---

### س2: كم تكلفة تشغيل المنظومة؟

**ج:** التكلفة الشهرية المتوقعة:
- **الحد الأدنى:** $20-30 (VPS + OpenAI basic)
- **المتوسط:** $45-95 (مع استخدام معتدل لـ APIs)
- **الكامل:** $100-150 (استخدام مكثف + ميزات متقدمة)

**مقارنة بالبدائل التقليدية:**
| البديل | التكلفة الشهرية |
|--------|-----------------|
| موظف استقبال | $500-800 |
| نظام CRM تجاري | $100-300 |
| أداة تحليلات | $50-200 |
| **منظومتنا** | **$45-95** ✅ |

---

### س3: هل أحتاج خبرة برمجية لتشغيل النظام؟

**ج:** 
- **المستوى الأساسي:** لا تحتاج خبرة (استخدم سكربت التثبيت `./scripts/setup.sh`)
- **المستوى المتوسط:** معرفة بسيطة بـ Docker و Linux تساعد في الصيانة
- **المستوى المتقدم:** معرفة بـ n8n و SQL للتخصيص والتوسع

### س5: هل يمكن تشغيل النظام على جهازي الشخصي؟

**ج:** نعم، للتجربة فقط:
```bash
# على جهازك المحلي (Linux/Mac)
git clone <repo-url>
cd n8n-Hajj-Umrah-Complete
docker compose up -d
```

**تحذير:** لا تستخدم للإنتاج على جهاز شخصي بسبب:
- مشاكل الأمان
- الحاجة لتشغيل 24/7
- عنوان IP ديناميكي

### س6: كيف أقوم بالنسخ الاحتياطي للبيانات؟

**ج:**
```bash
# نسخة احتياطية يومية تلقائية
0 2 * * * docker exec hajj_postgres pg_dump -U hajj_admin hajj_umrah_db > /backups/db_$(date +\%Y\%m\%d).sql

# استعادة النسخة
docker exec -i hajj_postgres psql -U hajj_admin -d hajj_umrah_db < backup.sql
```

**للوقاية:** فعل نظام المراقبة في F40 Backup & Recovery

## ⚖️ أسئلة شرعية

### س8: هل النظام معتمد شرعياً؟

**ج:** 
- ✅ النظام يستخدم فتاوى معتمدة من هيئات رسمية
- ✅ يوجد نظام مراجعة بشرية للأسئلة المعقدة (F7)
- ✅ جميع الأحكام موثقة ومراجعة

**تنبيه:** النظام ليس بديلاً عن العالم الشرعي في المسائل الدقيقة والنوازل.

---

### س9: ما هي الفتاوى التي يعتمد عليها النظام؟

**ج:**
1. **في النيابة بالحج والعمرة:**
   - فتاوى اللجنة الدائمة للإفتاء
   - فتاوى ابن باز، العثيمين، الفوزان
   - قرارات مجمع الفقه الإسلامي

2. **شروط صحة الإنابة:**
   - إذن الميت أو الورثة (للوفاة)
   - عجز الموكل الحقيقي (مرض، كبر سن)
   - إسلام الموكل والنائب
   - إحرام النائب عن نفسه أولاً إذا لم يحج

---

### س10: كيف يتعامل النظام مع الخلافات الفقهية؟

**ج:**
1. يذكر الأقوال المختلفة
2. يرجح بناءً على قوة الدليل
3. ينصح المستخدم بمراجعة عالم محلي للفتوى النهائية

مثال:
```
السؤال: هل تجزئ عمرة واحدة عن عدة موتى؟

الإجابة:
في هذه المسألة قولان لأهل العلم:
1. لا تجزئ، بل لكل ميت عمرة مستقلة (وهو الراجح)
2. تجزئ عن عدد غير محدود

نوصي بالاستفسار من عالم شرعي للترجيح حسب حالتك.
```

### س12: ما هو نظام "الثواب" (Token Economy)?

**ج:** نظام نقاط رمزي يحفز العملاء على:
- الإحالات: +100 نقطة لكل صديق
- التقييمات: +50 نقطة لتقييم 5 نجوم
- الصدقات: +200 نقطة للتبرع الإضافي

**الاستخدام:**
- 500 نقطة = خصم 10% على عمرة
- 1000 نقطة = عمرة مجانية واحدة
- التبرع بالنقاط لمشاريع خيرية (F26)

## 🚀 أسئلة التوسع

### س18: كم عمرة يمكن تنفيذ شهرياً؟

**ج:**
- **البداية:** 50-100 عمرة/شهر (فريق صغير)
- **المتوسط:** 500-1000 عمرة/شهر (أسطول منفذين)
- **الكامل:** 5000+ عمرة/شهر (مع الأتمتة الكاملة)

**معادلة التوسع:**
```
عدد المنفذين × 10 عمرات/شهر = السعة الشهرية
```

لتوسيع السعة:
1. فعل F17 Auto Recruiter
2. استخدم F16 Executor Fleet Manager
3. وزّع المنفذين على مكة والمدينة

## 🆘 أسئلة الطوارئ

### س20: ماذا لو حدث خطأ في عمرة؟

**ج:**
1. **نظام التبليغ:**
   - العميل يبلغ عبر Telegram
   - إنشاء ticket تلقائي

2. **التحقيق:**
   - مراجعة التسجيلات (F13 Golden Chain)

   - إذا الخطأ من المنفذ: إعادة التنفيذ مجاناً + تعويض
   - إذا سوء فهم: توضيح واعتذار
   - إذا نزاع: F12 Sharia Court

4. **التعلم:**
   - تسجيل الحالة في قاعدة المعرفة
   - تحسين النظام لمنع التكرار
