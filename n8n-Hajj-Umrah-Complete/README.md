## 🎯 الرؤية العامة

تهدف هذه المنظومة إلى إنشاء نظام ذاتي التطور يغطي دورة الحياة الكاملة لخدمات الحج والعمرة بالإنابة:

1. **اكتشاف العملاء** قبل أن يطلبوا عبر الرادار العالمي الذكي
2. **التحقق الشرعي** الآلي باستخدام الذكاء الاصطناعي
3. **تنفيذ العمرة** بشفافية مطلقة وتوثيق لحظي
4. **بناء وقف رقمي** دائم لضمان الاستمرارية

### المزايا الرئيسية

✅ **ميزانية شبه معدومة** - الاعتماد على الاشتراكات الحالية والخوادم الذاتية  
✅ **بدون تدخل بشري روتيني** - أتمتة كاملة بنسبة 95%+  
✅ **شفافية مطلقة** - توثيق كل خطوة وإثباتها  
✅ **نمو فيروسي** - العملاء يجلبون العملاء تلقائياً

    ┌───────────┐  ┌───────────┐  ┌───────────┐

## 🚀 دليل التثبيت السريع

### الخطوة 1: إعداد الخادم

```bash
# الدخول إلى الخادم
ssh root@your-vps-ip

# تحديث النظام
apt update && apt upgrade -y

# تثبيت Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh

# تثبيت Docker Compose
apt install docker-compose-plugin -y
```

### الخطوة 2: تحميل المشروع

```bash
cd /opt
git clone <repository-url> n8n-Hajj-Umrah-Complete
cd n8n-Hajj-Umrah-Complete
```

### الخطوة 3: إعداد متغيرات البيئة

```bash
# نسخ ملف الإعدادات
cp .env.example .env

# تحرير الملف وإضافة مفاتيح API
nano .env
```

**القيم المطلوبة في `.env`:**

```env
DB_PASSWORD=كلمة_سر_قوية
OPENAI_API_KEY=sk-your-key-here
APIFY_API_KEY=your-apify-key
TELEGRAM_BOT_TOKEN=bot-token-here
TELEGRAM_ADMIN_CHAT_ID=admin-chat-id
```

### الخطوة 4: تشغيل المنظومة

```bash
# تشغيل جميع الخدمات
docker compose up -d

# التحقق من الحالة
docker compose ps
```

### الخطوة 5: إعداد قاعدة البيانات

```bash
# الدخول إلى حاوية PostgreSQL
docker exec -it hajj_postgres psql -U hajj_admin -d hajj_umrah_db

# تنفيذ مخطط القاعدة
\i /scripts/database_schema.sql

# الخروج
\q
```

### الخطوة 6: الوصول إلى الواجهات

| الخدمة | الرابط | بيانات الدخول |
|--------|--------|--------------|
| n8n | http://your-ip:5678 | يتم إنشاؤها عند أول دخول |
| Metabase | http://your-ip:3000 | admin/password (غيّرها!) |
| MinIO Console | http://your-ip:9001 | minio_admin/minio_secure_password |

## 🔧 الصيانة والتشغيل

### المراقبة اليومية

```bash
# حالة الخدمات
docker compose ps

# سجلات n8n
docker logs hajj_n8n --tail 100

# استخدام الموارد
docker stats
```

### النسخ الاحتياطي

```bash
# نسخة احتياطية من قاعدة البيانات
docker exec hajj_postgres pg_dump -U hajj_admin hajj_umrah_db > backup_$(date +%Y%m%d).sql

# نسخة من ملفات n8n
docker cp hajj_n8n:/home/node/.n8n ./n8n-backup-$(date +%Y%m%d)
```

### التحديثات

```bash
# تحديث الصور
docker compose pull

# إعادة التشغيل
docker compose down && docker compose up -d
```
